2. 写 `sql/patch/NNN_描述.sql`（现网环境），要求幂等（`where not exists` / `if not exists`），编号递增。
3. 执行：`PGPASSWORD=postgres psql -h 127.0.0.1 -U root -d fba -f <patch>`。
4. 遇 `ix_sys_role_menu_id` 唯一冲突 → `select setval('sys_role_menu_id_seq', (select max(id) from sys_role_menu));` 后重试。
