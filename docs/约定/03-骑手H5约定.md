# 03 · 骑手 H5 约定（`rider-h5/`）

> 独立 Vue 3 应用，不在 FBA 前端仓库内，可自由增删文件与依赖（pnpm）。为什么独立：见 `00-架构决策纲要` §0.2。

## 1. 技术栈与运行

- Vue 3 + Vite + TypeScript + Vant 4 + Pinia + vue-router + axios + dayjs。
- 端口固定 **5174**（`vite.config.ts` `server.port`）；`start_all.sh` 一并拉起，日志 `.runtime/logs/rider-h5.log`。
- 环境变量 `VITE_API_BASE`（`.env.development` / `.env.production`），默认 `http://127.0.0.1:8000`。
- 后端 CORS：H5 源必须在 `fastapi-best-architecture/backend/.env` 的 `CORS_ALLOWED_ORIGINS` JSON 数组中；改后重启后端。开发用 `http://localhost:5174` 打开。
- 桌面预览居中，最大宽 480px（`styles/theme.css`）。

## 3. 请求约定

- 所有请求走 `request<T>(config)`（`api/http.ts`），返回已解包的 `data`；业务失败（`code !== 200`）自动 toast 并 reject。
- 可选配置：`skipToast`（不弹错误）、`skipAuthRedirect`（401 不跳登录）。
- 401 → 清 token 跳 `/login`。资料接口 403、且消息不含「查阅期限」→ 提示「仅骑手可用」。403 且消息含「不是有效骑手」或「查阅期限」→ 清 token 跳登录；离职超过 90 天用后端原文，不说成仅骑手可用。
- **只允许调用**：`/api/v1/auth/*`、`/api/v1/rider-salary/me/*`。改密走 `PUT /api/v1/rider-salary/me/password`（成功后清除必须改密标记）。管理端接口一律不调（后端也会 403）。
- 响应 `code` 为 `423` 且 `data.error_code` 为 `MUST_CHANGE_PASSWORD`（文案「请先修改初始密码」）时，保留 token 并跳到 `/change-password`。
- `/me/*` 接口清单与返回结构见 `docs/设计/03-后端骨架说明.md` §9。

## 4. 路由

- 每个页面 `meta.title`（中文）；底部 Tab 页加 `meta.tab`（`home/adjustments/advance/notices/me`），`AppTabbar` 据此高亮。
- 公共页 `meta.public: true`（目前只有 `/login`）。守卫：无 token 且非 public → `/login`；有 token 访问 `/login` → `/home`。
- 须改密时进入 `/change-password`（需登录，无底部 Tab）。改密成功后进入首页。
- 兜底 `/:pathMatch(.*)*` → `/home`。
- 详情类路由带参数，如 `/day/:date`。
- 往期工资：`/payslips` 按周期列出已定稿或已发薪的有效工资条，`/payslips/:id` 看明细。入口在首页和「我的」，不是底部 Tab。离职后 90 天内只读，不能提交或撤回预支。

## 5. UI 约定

- 组件用 Vant 4（`van-*`），文案全中文。
- 金额用 `MoneyText`/`formatMoney`；负数红色。
- 日历复用 `components/SalaryCalendar.vue`（与管理端同款视觉：方案色带 + 日格）。
- 预估金额必须标注「预估」（`is_estimate=true` 时）。
- 空状态用 `van-empty` 并给出下一步（如「暂无公告」）。
- 预支申请前先查 `/me/advance-limit`，超额或已有在途单在前端直接禁用按钮并提示。

## 6. 登录

- 用户名=工号。未指定密码时由服务端生成随机口令，只在开户或重置的当次响应里返回；开户和重置都会要求首次登录改密。已灌演示骑手的 `must_change_password` 为 false，仍用种子口令直接登录。
- 需要图形验证码：`GET /api/v1/auth/captcha` 取 `uuid` + 图片，登录 body 带 `uuid`/`captcha`。
- 限流：登录约 5 次/分钟，验证码约 5 次/30 秒；失败提示后端 msg。
