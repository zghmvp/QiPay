# 01 · 后端开发约定（`backend/plugin/rider_salary`）

> 基于当前仓库真实代码提炼。示例均取自 `site` 模块，可直接照抄结构。工具函数签名详见 `docs/设计/03-后端骨架说明.md` §3。

## 0. 边界

- 只能改 `fastapi-best-architecture/backend/plugin/rider_salary/**` 与 `backend/.env`。
- 新依赖写 `requirements.txt`，用 `uv pip install -r backend/plugin/rider_salary/requirements.txt` 装进 `.venv`，不动 `pyproject.toml`/`uv.lock`。
- 配置项只加在 `plugin.toml [settings]`，代码里 `from backend.core.conf import settings` 读取 `settings.RIDER_SALARY_XXX`。

## 2. 各层模板

### 2.1 Model（`model/site.py`）

```python
class RiderSalarySite(Base):
    """站点表"""

    __tablename__ = 'rs_site'
    __table_args__ = (
        sa.UniqueConstraint('code', 'deleted', name='uk_rs_site_code_deleted'),
        {'comment': '站点表'},
    )

    id: Mapped[id_key] = mapped_column(init=False)
    code: Mapped[str] = mapped_column(sa.String(32), comment='站点编码')
    settle_cycle: Mapped[str] = mapped_column(sa.String(20), default=CycleType.month.value, comment='结算周期类型')
    advance_limit: Mapped[Decimal | None] = mapped_column(sa.Numeric(12, 2), default=None, comment='预支上限（站点级）')
    remark: Mapped[str | None] = mapped_column(UniversalText, default=None, comment='备注')
```

- 类名 `RiderSalaryXxx`，表名 `rs_xxx`；继承 FBA `Base`（带 `created_time/updated_time/deleted/deleted_time`）；仅审计日志 `RiderSalaryAuditLog` 继承 `DataClassBase`。
- 枚举列存 `sa.String(20)`，默认值写 `Enum.member.value`，**不用数据库 ENUM**。
- 唯一约束必须带 `deleted` 列（逻辑删除后可复用编码）。
- 金额 `Numeric(12,2)`，单价 `Numeric(10,4)`，距离/重量 `Numeric(8,2)`；长文本 `UniversalText`；JSON `sa.JSON()`。
- 每列必有中文 `comment`。
- 新模型必须在 `model/__init__.py` import，否则 `create_all` 不建表。

### 2.2 Schema（`schema/site.py`）

```python
class SiteSchemaBase(SchemaBase):
    """站点基础模型"""
    code: str = Field(description='站点编码')
    settle_cycle: CycleType = Field(CycleType.month, description='结算周期类型')

class CreateSiteParam(SiteSchemaBase):
    """创建站点参数"""

class UpdateSiteParam(SchemaBase):
    """更新站点参数"""          # 所有字段 Optional，默认 None
    code: str | None = Field(None, description='站点编码')

class GetSiteDetail(SiteSchemaBase):
    """站点详情"""
    model_config = ConfigDict(from_attributes=True)
    id: int = Field(description='站点 ID')
    created_time: datetime = Field(description='创建时间')

    @computed_field  # type: ignore[prop-decorator]
    @property
    def status_label(self) -> str:
        """状态中文"""
        try:
            return EnableStatus(self.status).label
        except ValueError:
            return str(self.status)
```

- 命名固定：`XxxSchemaBase` / `CreateXxxParam` / `UpdateXxxParam` / `GetXxxDetail`；动作类参数 `XxxYyyParam`（如 `RiderLeaveParam`、`RollbackParam`）。
- 请求侧枚举字段用枚举类型（`CycleType`）；响应侧可继承基类的枚举类型，但**必须**配 `xxx_label` computed_field（`try: Enum(value).label except ValueError: str(value)`），前端优先用后端 label。
- 每个字段必有中文 `description`；类必有中文 docstring。
- 需要 `reason` 的动作在 Param 里加 `reason: str | None = Field(None, description='操作原因')`，由 Service 调 `require_reason` 校验。

### 2.3 CRUD（`crud/site.py`）

```python
class CRUDSite(CRUDPlus[RiderSalarySite]):
    """站点数据库操作"""

    async def get(self, db: AsyncSession, pk: int) -> RiderSalarySite | None:
        return await self.select_model(db, pk, deleted=0)

    async def get_select(self, name: str | None, ..., site_ids: set[int] | None) -> Select:
        filters: dict = {'deleted': 0}
        if name:
            filters['name__like'] = f'%{name}%'
        if site_ids is not None:
            filters['id__in'] = list(site_ids) or [-1]   # 空集合 → 查不到任何行
        return await self.select_order('id', 'desc', **filters)

    async def create(self, db, obj: CreateSiteParam) -> RiderSalarySite:
        return await self.create_model(db, obj, flush=True)

    async def update(self, db, pk: int, obj: UpdateSiteParam) -> int:
        return await self.update_model_by_column(db, obj, id=pk, deleted=0)

    async def delete(self, db, pk: int) -> int:
        return await self.delete_model_by_column(
            db, logical_deletion=True, deleted_flag_column='deleted',
            deleted_flag_value=self.model.id, deleted_at_column='deleted_time',
            deleted_at_factory=timezone.now, id=pk, deleted=0,
        )

site_dao: CRUDSite = CRUDSite(RiderSalarySite)
```

- 类名 `CRUDXxx`，单例 `xxx_dao`。所有查询带 `deleted=0`。
- 列表查询返回 `Select`（`get_select`），由 Service 交给 `paging_data`。
- 逻辑删除固定用上面这组参数（`deleted_flag_value=self.model.id` 让唯一约束可复用）。
- CRUD 不 `commit`；事务由 API 层 `CurrentSessionTransaction` 控制。需要立刻拿 id 时 `flush=True`。

### 2.4 Service（`service/site_service.py`）

```python
_SITE_FIELDS = ('id', 'code', 'name', ...)   # 审计快照字段白名单

class SiteService:
    """站点服务"""

    @staticmethod
    async def get(*, db: AsyncSession, request: Request, pk: int) -> Any:
        site = await site_dao.get(db, pk)
        if not site:
            raise errors.NotFoundError(msg='站点不存在')
        visible = await get_visible_site_ids(request, db)
        assert_site_visible(visible, site.id)
        return site

    @staticmethod
    async def get_list(*, db, request, name, code, status) -> dict[str, Any]:
        visible = await get_visible_site_ids(request, db)
        stmt = await site_dao.get_select(name=name, code=code, status=status, site_ids=visible)
        return await paging_data(db, stmt)

site_service: SiteService = SiteService()
```

- 类名 `XxxService`，全 `@staticmethod`，关键字参数，单例 `xxx_service`。
- **站点数据范围**：所有涉及站点的读写先 `get_visible_site_ids(request, db)`（超管/薪资管理员 → `None`；否则该用户 `rs_site_manager` 的站点集合），再 `assert_site_visible(visible, site_id)` 或把集合传给 CRUD 过滤。
- 异常只用 `backend.common.exception.errors` 的类（`NotFoundError` / `RequestError` / `ForbiddenError` / `ConflictError` / `ServerError`），`msg` 中文。
- 校验顺序：存在性 → 可见性 → 业务规则 → 锁账 → 写 → 重算标记 → 审计。

### 2.5 API（`api/v1/site.py`）

```python
router = APIRouter()

@router.get('', summary='分页获取站点', dependencies=[DependsJwtAuth, DependsPagination, DependsRBAC])
async def get_sites_paginated(
    db: CurrentSession, request: Request,
    name: Annotated[str | None, Query(description='站点名称')] = None,
) -> ResponseSchemaModel[PageData[GetSiteDetail]]:
    page_data = await site_service.get_list(db=db, request=request, name=name, ...)
    return response_base.success(data=page_data)

@router.post('', summary='创建站点', dependencies=[Depends(RequestPermission('rs:site:add')), DependsRBAC])
async def create_site(db: CurrentSessionTransaction, request: Request, obj: CreateSiteParam) -> ResponseModel:
    await site_service.create(db=db, request=request, obj=obj)
    return response_base.success()

@router.put('/{pk}', summary='更新站点', dependencies=[Depends(RequestPermission('rs:site:edit')), DependsRBAC])
async def update_site(db: CurrentSessionTransaction, request: Request,
                      pk: Annotated[int, Path(description='站点 ID')], obj: UpdateSiteParam) -> ResponseModel:
    count = await site_service.update(db=db, request=request, pk=pk, obj=obj)
    return response_base.success() if count > 0 else response_base.fail()
```

| 场景 | `dependencies` | `db` 类型 | 返回类型 |
|---|---|---|---|
| 只读 | `DependsJwtAuth, DependsRBAC` | `CurrentSession` | `ResponseSchemaModel[T]` |
| 只读分页 | `DependsJwtAuth, DependsPagination, DependsRBAC` | `CurrentSession` | `ResponseSchemaModel[PageData[T]]` |
| 写 | `Depends(RequestPermission('rs:模块:动作')), DependsRBAC` | `CurrentSessionTransaction` | `ResponseModel` |
| 骑手端 `/me/*` | `dependencies=[DependsJwtAuth]`，函数参数 `rider: Rider = DependsCurrentRider`（**不挂 RBAC**） | 按读写 | 同上 |

- 新写的只读接口按上表挂 `DependsRBAC`；历史上有少数只读接口只挂了 `DependsJwtAuth`（如 `GET /orders`、`/engine/*` 元数据），以及 `GET /riders` 误挂 `rs:rider:add`（观察项），改到时顺手对齐，不要新增同类不一致。

- 路由顺序：静态路径（`/all`、`/export`、`/active`）写在 `/{pk}` **之前**，避免被参数路由吞掉。
- 路径参数 `Annotated[int, Path(description='…')]`，查询参数 `Annotated[T | None, Query(description='…')] = None`。
- 新路由文件在 `api/router.py` 用 `v1.include_router(xxx_router, prefix='/xxxs', tags=['中文模块名'])` 注册；资源名复数 kebab-case。
- 权限码 `rs:<module>:<action>`，必须与 `sql/*/init.sql` 里 `sys_menu.perms` 完全一致。

## 3. 枚举

`enums.py` 全部为 `LabeledStrEnum`，用 `_bind_labels(Enum, {member: '中文'})` 绑定，`Enum.member.label` 取中文，`Enum.LABELS` 取全表。新增枚举后：

1. 前端 `constants/enums.ts` 同步一份 `XXX_OPTIONS`（value/label/color）；
2. 若前端有筛选/Tag，颜色在前端定；
3. 响应 Schema 加 `xxx_label` computed_field。

## 4. 写操作三件套（影响算薪的表必做）

适用表：`rs_order`、`rs_adjustment`、`rs_rider_plan_binding`、`rs_day_flag`、`rs_rider_employ_history`（以及间接影响的 `rs_rider.employ_type`）。

```python
# 1) 锁账校验（写前）
await assert_not_locked(db, site_id=rider.site_id, rider_id=rider.id, biz_date=obj.start_date)
# 区间写操作两端都要查：start_date 与 end_date（end 为空则只查 start）

# 2) 写
row = await xxx_dao.create(db, ...)

# 3) 重算标记（写后）
await mark_stale(db, rider_ids=[pk], date_from=obj.start_date, date_to=_as_end(obj.end_date))

# 4) 审计
await audit_service.record(
    db, request,
    module='骑手管理', action='新增方案绑定',
    target_type='rider_plan_binding', target_id=row.id,
    target_label=f'{rider.job_no} {rider.name}',
    reason=obj.reason,                       # 需原因的动作先 require_reason(action, reason)
    before=None, after=snapshot(row, _FIELDS),
)
```

- `module` 用中文模块名（与前端 `AUDIT_MODULE_OPTIONS` 一致）；`action` 中文动词短语。
- `snapshot(obj, fields)` 只快照白名单字段；更新操作 `before` 取更新前快照、`after` 取重新 `get` 后的快照。
- 需要原因的动作列表：`utils/audit.py` `REASON_REQUIRED_ACTIONS`；新增需原因的动作要同时加中文名与英文别名。
- 锁账/发薪状态判断统一用 `utils/lock_check.is_status_locked`，不要手写 `status in ('locked','paid')`。

## 5. 时间、金额、日期

- 当前时间 `timezone.now()`；业务日期 `date` 类型，列名 `biz_date` / `start_date` / `end_date`。
- 时段类字段（下单/送达时刻）求值前转 **Asia/Shanghai**，再取时分（见踩坑 #5）。
- 金额一律 `Decimal`；四舍五入 `utils.money.q2()`（`ROUND_HALF_UP` 到 2 位）；禁止 `float`。
- 区间语义：闭区间 `[start_date, end_date]`；`end_date=None` 表示长期，比较时用 `_as_end()` 转成 `date.max`。
- 阶梯档位：含下限、不含上限，最后一档 `上限=null`。

## 6. SQL 种子与增量

### 6.1 四份 init 文件必须同步改

`sql/postgresql/init.sql`、`sql/postgresql/init_snowflake.sql`、`sql/mysql/init.sql`、`sql/mysql/init_snowflake.sql`。雪花 ID = `2060000000000000000 + 自增 ID`。

| 对象 | 自增 ID 段 | 说明 |
|---|---|---|
| 页面菜单 `sys_menu` type=1 | `91001–91099` | `parent_id=91000`；隐藏页 `display=0`（如 91006 方案编辑器、91015 骑手档案） |
| 按钮权限 `sys_menu` type=2 | `91101–91199` | `perms='rs:x:y'`，`parent_id`=所属页面 |
| 角色 `sys_role` | `92001 薪资管理员 / 92002 站点负责人 / 92003 站点副负责人 / 92004 骑手` | |
| 角色菜单 `sys_role_menu` | `93001+` | 新增时取当前最大 +1，三个角色各一行 |
| 内置科目 `rs_subject` | `94001+` | `is_builtin=true` |

- **文件开头不能有 `--` 注释**（`fba init` 的 SQL 解析器会拒绝整单回滚）。
- `init.sql` 只放菜单/角色/科目等种子；业务表由模型 `create_all` 建，**不写 CREATE TABLE**。
- PostgreSQL 文件末尾保留 `setval(pg_get_serial_sequence(...))` 四条，保证自增序列跳过种子 ID。
- `component` 路径必须与前端文件一致：`/plugins/rider-salary/views/<module>/<file>`（不带 `.vue`）。

### 6.2 对已初始化库做增量：`sql/patch/NNN_描述.sql`

现网库不会重跑 init。每次菜单/权限/角色/科目变更，除改 4 份 init 外，再写一份幂等补丁并执行：

```sql
insert into sys_menu (id, title, name, path, sort, icon, type, component, perms, status, display, cache, link, remark, parent_id, created_time, updated_time)
select 91015, '骑手档案', 'RiderSalaryRiderDetail', '/rider-salary/rider/:id', 15, 'lucide:user-round', 1,
       '/plugins/rider-salary/views/rider/detail', null, 1, 0, 1, '', null, 91000, now(), null
where not exists (select 1 from sys_menu where id = 91015);

insert into sys_role_menu (role_id, menu_id)
select 92001, 91015 where not exists (select 1 from sys_role_menu where role_id = 92001 and menu_id = 91015);
-- 92002 / 92003 同样各一条（完整示例见 sql/patch/001_rider_detail_menu.sql）
```

执行：`PGPASSWORD=postgres psql -h 127.0.0.1 -U root -d fba -f backend/plugin/rider_salary/sql/patch/001_rider_detail_menu.sql`。`sys_role_menu` 若报 `ix_sys_role_menu_id` 冲突，说明序列落后于种子 ID：先 `select setval('sys_role_menu_id_seq', (select max(id) from sys_role_menu))` 再插。

### 6.3 重建插件表

停服务 → `psql -f sql/postgresql/destroy.sql` → 启动后端（`create_all` 建表）→ `psql -f sql/postgresql/init.sql` → 依次执行 `sql/patch/*.sql`。**不要在共享库上跑 `fba init`**（会 drop 全部 ORM 表）。

## 8. 代码风格

- 遵循 FBA ruff 配置：单引号、行宽 120、import 分组。写完跑 `uv run ruff check backend/plugin/rider_salary && uv run ruff format backend/plugin/rider_salary`。
- 注释/docstring 中文；函数 docstring 用 `:param x: 说明` 形式（与 FBA 一致）。
- 私有常量/函数下划线前缀（`_SITE_FIELDS`、`_as_end`）。

- 不做「顺手重构」；发现他人模块问题写进回复的「需用户决策」。

## 9. 公式引擎扩展

- 新字段：`engine/fields.py` `FIELDS` 加 `FieldSpec(中文名, 类型, 适用阶段, 单位, 说明, 枚举项)`，并在 `engine/context.py` 提供取值；前端由 `GET /engine/fields` 自动拉取，`views/plan/helpers.ts` `FIELD_GROUPS` 决定分组显示，需同步加进分组。
- 新函数：`engine/functions.py` 注册中文函数名；`GET /engine/functions` 自动暴露。
- 新公式类型/模板：`engine/compiler.py` `FORMULA_TEMPLATES`；前端 `helpers.ts` `defaultFormula/formulaKindOf/summarizeFormula` 与 `FormulaBuilder.vue` 同步。
- 三阶段固定顺序 `per_order → daily → period`，同阶段按 `sort_order`；周期项引用「本期已计金额」时必须排在最后（保底类）。
