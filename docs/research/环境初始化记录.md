## 4. 登录接口 curl 示例

登录验证码默认开启（`LOGIN_CAPTCHA_ENABLED=true`，参数配置插件会在登录时动态覆盖）。不要改 `conf.py`。开发验证可从 Redis 取出验证码明文。

```bash
# 1) 取验证码 uuid
CAPTCHA=$(curl -sS http://127.0.0.1:8000/api/v1/auth/captcha)
UUID=$(python3 -c 'import json,sys; print(json.load(sys.stdin)["data"]["uuid"])' <<<"$CAPTCHA")
CODE=$(redis-cli GET "fba:login:captcha:$UUID")

# 2) JSON 登录拿 token
LOGIN=$(curl -sS -X POST http://127.0.0.1:8000/api/v1/auth/login \
  -H 'Content-Type: application/json' \
  -d "{\"username\":\"admin\",\"password\":\"123456\",\"uuid\":\"$UUID\",\"captcha\":\"$CODE\"}")
TOKEN=$(python3 -c 'import json,sys; print(json.load(sys.stdin)["data"]["access_token"])' <<<"$LOGIN")

# 3) 受保护接口：当前用户
curl -sS http://127.0.0.1:8000/api/v1/sys/users/me \
  -H "Authorization: Bearer $TOKEN"
```

本次验证结果：`POST /api/v1/auth/login` → 200，`GET /api/v1/sys/users/me` → 200，用户名 `admin`。

无验证码快捷通道（Swagger 调试专用，HTTP Basic）：

```bash
curl -sS -u admin:123456 -X POST http://127.0.0.1:8000/api/v1/auth/login/swagger
```

注意：`POST /api/v1/auth/login` 有速率限制（约每分钟 5 次）。

## 7. 遇到的问题与解决办法

1. **PostgreSQL 未监听 5432**  
   FlyEnv 实例于 2026-09-07 09:58 被 fast shutdown。用 `pg_ctl -D ~/Library/FlyEnv/server/postgresql/postgresql18 start` 拉起。

2. **`postmaster 变成多线程` 启动失败**  
   日志提示设定合法 `LC_ALL`。当前 shell `LANG=""` / `LC_*="C"` 会触发 PostgreSQL 18 在 macOS 上的启动失败。解决：`export LC_ALL=en_US.UTF-8 LANG=en_US.UTF-8` 后再 `pg_ctl start`。`start_all.sh` 已内置。

3. **`brew services` 不可用**  
   Homebrew 报 `undefined method 'stop_timeout'`。改用 `pg_ctl`，不要依赖 `brew services start`。

4. **角色 `zghmvp` 不存在**  
   本实例超级用户是 `root` / `postgres`（角色名），不是 macOS 用户名。`.env` 使用 `DATABASE_USER=root`、`DATABASE_PASSWORD=postgres`。连库：`PGPASSWORD=postgres psql -h 127.0.0.1 -U root -d fba`。**不要连接或改动 `fba_rpp`。**

5. **默认 Python 3.14.6**  
   用 `uv python install 3.12` + `uv sync --group dev --python 3.12` 创建 `.venv`（3.12.13）。未写入 `.python-version`，以免改仓库文件。

6. **`fba init` 交互确认**  
   Rich Prompt 默认 `n`。非交互：`printf 'y\n' | uv run fba init`。

7. **`fba` 库于 13:2x 被清空后重建**  
   旧钉钉遗留表已不在。当前为干净 ORM 表 + 种子。`fba_rpp` 未动。

8. **登录验证码**  
   不能改 `conf.py`；动态配置插件也会把开关设为 true。测试从 Redis 读 `fba:login:captcha:<uuid>`，或走 `/auth/login/swagger`。

9. **Node 26 vs engines 22/24**  
   `pnpm install` 仅 WARN，依赖装完，Vite 8.0.10 可启动。`pnpm 11` 无 `--ignore-engines` 选项。

10. **lefthook**  
    `CI=true pnpm install` 使 `is-ci` 为真，跳过 `lefthook install`。

11. **后台进程被 shell 退出带走**  
    macOS 无 `setsid`。`start_all.sh` 用 Python `Popen(..., start_new_session=True)` 脱离会话。Agent 直接 `nohup ... &` 结束命令后可能收不到进程。

12. **登录限流**  
    `/auth/login`、`/auth/captcha` 有 pyrate-limiter，频繁 curl 会 429。
