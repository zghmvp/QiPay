# 本地开发说明

给在自己电脑上用 Cursor 打开本仓库的人。克隆后按本文把管理端、后端、骑手 H5 跑起来。规则和命令以 `AGENTS.md` 为准，环境细节以 `docs/research/环境初始化记录.md` 为准。两边已经写过的步骤，这里只指出章节，不另写一套。

用 Cursor 打开仓库根目录。进入后先读 `AGENTS.md`。

## 1. 克隆

计划改动在分支 `cursor/qipay-plan-batch`。

```bash
git clone -b cursor/qipay-plan-batch https://github.com/zghmvp/QiPay.git
cd QiPay
```

## 2. 三个单元改哪里

| 单元 | 只改这里 | 端口 |
|---|---|---|
| 后端插件 | `fastapi-best-architecture/backend/plugin/rider_salary/` | 8000 |
| 管理端前端插件 | `fastapi-best-architecture-ui/apps/web-antdv-next/src/plugins/rider-salary/` | 5173 |
| 骑手 H5 | `rider-h5/`（自有应用，可自由改） | 5174 |

禁止改 FBA 框架代码。后端框架、管理端框架都不动。唯一例外是 `fastapi-best-architecture/backend/.env`（本机环境，可写数据库和 CORS，不要提交）。确需改框架时停下来，按 `AGENTS.md` §2 写框架修改申请。

可见文案用中文。管理端新页面的路由不写在前端 `routes/index.ts`，写在数据库菜单里，见下文第 7 节。

## 3. 依赖

本机需要：

- Python 3.12，以及 [uv](https://docs.astral.sh/uv/)
- Node.js `^22.18.0` 或 `^24.0.0`（管理端 `engines`）
- pnpm 11（仓库锁定 `pnpm@11.7.0`；管理端目录里用 corepack 按 `packageManager` 切换）
- PostgreSQL 16，监听 `127.0.0.1:5432`
- Redis，监听 `127.0.0.1:6379`

版本和「脚本不负责安装数据库」见 `docs/research/环境初始化记录.md` §1。那份记录里的 macOS Homebrew、FlyEnv 路径已经作废，不要照做。

## 4. 数据库、Redis 和 `.env`

先让 PostgreSQL 和 Redis 在本机监听。`scripts/start_all.sh` 只检测 `127.0.0.1:5432` 和 `127.0.0.1:6379`，不会安装，也不会替你拉起。未监听时的启动方式见环境初始化记录 §3.3、§7。

在 `fastapi-best-architecture/backend/` 把 `.env.example` 复制为 `.env`，按你本机的库改连接项。`.env` 被 git 忽略，不要提交。`.env.example` 里的用户名和密码是框架模板，复制后改成你本机实际账号。本仓库已经记过的一套本地取值在环境初始化记录 §8（库名 `fba`，主键模式自增）。

建库、连库、重置插件表见环境初始化记录 §3.3、§5，以及 `docs/约定/01-后端开发约定.md` §6.3。已有数据的库不要跑 `fba init`，它会删掉全部 ORM 表。

## 5. 启动和停止

在仓库根目录：

```bash
scripts/start_all.sh
scripts/stop_all.sh
```

| 服务 | 地址 |
|---|---|
| 后端 API | http://127.0.0.1:8000/api/v1 |
| Swagger | http://127.0.0.1:8000/docs |
| 管理端 | http://127.0.0.1:5173/ |
| 骑手 H5 | http://127.0.0.1:5174/ |

日志在 `.runtime/logs/`，PID 在 `.runtime/`。`stop_all.sh` 只停这三个应用，不停 PostgreSQL 和 Redis。分开启动的命令见环境初始化记录 §3。开发时后端可以去掉 `--no-reload`，改代码后自动加载。

登录要图形验证码。接口默认开着验证码，不要改框架 `conf.py`。取法：先请求验证码拿到 uuid，再从 Redis 读 `fba:login:captcha:<uuid>`。完整 curl 在环境初始化记录 §4。`/auth/login` 大约每分钟 5 次，太频繁会 429。

## 7. 页面路由在数据库菜单里

管理端打开哪个页面，由数据库表 `sys_menu` 决定，不是前端路由文件。新增页面（含隐藏详情页）要在 4 份 `sql/*/init*.sql` 里加菜单并绑定角色，再给当前库执行 `sql/patch/` 里的增量 SQL，否则页面 404。步骤见 `docs/约定/02-管理端前端约定.md` §1。

## 8. 测试和格式

命令与 `AGENTS.md` §3 相同。

后端在 `fastapi-best-architecture` 目录：

```bash
uv run --python 3.12 pytest backend/plugin/rider_salary/tests -q
uv run ruff check backend/plugin/rider_salary && uv run ruff format backend/plugin/rider_salary
```

管理端类型检查在 `fastapi-best-architecture-ui/apps/web-antdv-next` 目录，只看插件报错：

```bash
npx vue-tsc --noEmit -p tsconfig.json 2>&1 | rg "rider-salary"
```

影响算薪的写操作仍走锁账、重算、审计，见 `AGENTS.md` §2。
