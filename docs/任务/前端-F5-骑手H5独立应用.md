## 技术栈
`pnpm create vite`（vue-ts）+ `vant@4`（按需引入 unplugin-vue-components 或全量）+ `vue-router@4` + `pinia` + `axios` + `dayjs`。端口固定 5174（vite.config `server.port`）。`.env.development`：`VITE_API_BASE=http://127.0.0.1:8000`。移动端 viewport meta；`max-width: 480px` 居中，桌面预览也可用。

## 页面（全部中文，Vant 组件）
1. `/login`：工号、密码、图形验证码（点击刷新）、登录；登录成功存 token（localStorage）→ `/home`；接口错误显示后端 msg。
2. `/home`：顶部问候「{姓名} · {站点}」+ 当前生效方案短名 Tag；「本期预计工资」卡片（`/me/payroll-estimate`：周期区间、状态、单量、应发、代扣、预支抵扣、预计实发，`is_estimate` 时显示「预估」角标）；月份切换 + 月历（7 列、周一起始、色带简化为每格顶部一条细色条并在段首显示短名；每格显示单量与奖惩净额符号点；日状态用灰/红点区分）；底部 Tabbar：首页 / 奖惩 / 预支 / 公告 / 我的。
3. `/day/:date`：当日方案、订单列表（`van-cell` 折叠：订单号/时间/距离/重量/金额与命中的科目名），奖惩明细。
4. `/adjustments`：按月列表，按日期分组，金额带色。
5. `/plan`：当前与未来方案：方案名、版本、模式、生效区间、项名称与科目（不展示公式）。
6. `/advance`：顶部额度卡（上限/在途/可用，`/me/advance-limit`）；「申请预支」表单（金额、原因，提交前校验）；我的预支列表（状态 Tag、时间线）；pending 可「撤回」。
7. `/notices`：公告列表 + 详情。
8. `/me`：个人信息、修改密码（如 FBA 有 `/api/v1/sys/users/{id}/password` 类接口则接，否则不做并注明）、退出登录。

## 通用
- axios 拦截器：注入 `Authorization: Bearer`；401 → 清 token 跳 `/login`；统一 `van-toast` 展示后端 `msg`。
- 路由守卫：无 token 只允许 `/login`。
- 非骑手账号登录（`/me/profile` 返回 403）→ 提示「当前账号不是有效骑手账号」并登出。
- `README.md`：启动命令、端口、环境变量、与后端 CORS 配置说明。
