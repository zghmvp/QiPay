# 任务 F1 · 前端插件骨架 + 主数据页面

先读 `docs/任务/前端-F0-通用约定.md` 及其必读清单。你负责建立插件骨架（其他前端模块依赖你），再实现 7 个页面。

## 1. 骨架（先做并尽快可用）
- `plugin.toml`（summary='骑手薪资 UI'，description='骑手薪资管理插件的前端实现'，version 0.1.0，author QiPay，tags ['other']）
- `constants/enums.ts`：从后端 `enums.py` 逐个搬运（英文值、中文 label、Tag 颜色）。
- `utils/money.ts`、`utils/date.ts`、`types/common.ts`（分页参数/返回类型）。
- `components/`：SiteSelect、RiderSelect、SubjectSelect、ReasonModal、StatusTag、MoneyText。
- `api/`：site.ts rider.ts subject.ts adjustment.ts day-flag.ts notice.ts audit.ts（对应后端 D2 接口，字段以后端 schema 为准）。
- 一个 `views/_shared/PageContainer.vue`（可选）统一页面留白。

## 2. 页面
1. **站点管理** `views/site/index.vue`：vxe 列表（编码/名称/周期类型/周期配置摘要/预支上限/状态/负责人数）；新增/编辑抽屉（周期类型切换时动态显示 anchor_day）；「负责人」抽屉：`a-transfer` 或双列表，从 FBA 用户列表（`/api/v1/sys/users` 分页搜索）选人并设 owner/deputy（owner 最多 1）；删除二次确认。
2. **骑手管理** `views/rider/index.vue`：筛选（站点/状态/用工类型/关键字）；列表（工号/姓名/站点/用工类型/状态/当前方案短名(带颜色点)/账号状态）；新增/编辑抽屉；行操作：「方案绑定」抽屉（上方 `a-timeline` 或表格展示绑定区间，默认/覆盖分别标色；下方新增绑定表单：版本下拉 `GET /plan-versions/active`、类型、起止日期；后端报错重叠直接展示）、「用工类型历史」抽屉、「账号」下拉菜单（开通/重置密码/停用/启用，均走 ReasonModal 或密码输入）、「离职」（日期+原因）。
3. **科目管理** `views/subject/index.vue`：列表（编码/名称/方向 Tag/计费方式/定额/是否进应发/入账粒度/内置/状态）；新增/编辑抽屉（内置科目禁用不可改字段）；删除被拒时展示后端引用计数文案。
4. **奖惩录入** `views/adjustment/index.vue`：顶部筛选（站点/骑手/日期范围/科目/方向）；列表含锁账图标；「单条录入」抽屉；「批量录入」弹窗：可编辑表格（vxe 可编辑或 antd 表格 + 行内表单），每行 骑手/日期/科目/金额/备注，科目为定额时自动填金额，提交 `/adjustments/batch`，失败按行号高亮并显示原因；编辑/删除走 ReasonModal。
5. **日标记** `views/day-flag/index.vue`：选站点+月份 → 7 列月历（复用 `utils/date.ts` 的矩阵，周一起始）每格三个开关/复选（恶劣天气/高温/大促）+ 备注图标，底部「保存」一次性 PUT；锁账日禁用并提示。
6. **站点公告** `views/notice/index.vue`：列表 + 新增/编辑抽屉（站点可选「全部站点」）+ 发布/下线。
7. **操作日志** `views/audit/index.vue`：筛选（模块/动作/操作人/日期范围/关键字）；列表主列显示 `description`；行展开显示 before/after JSON diff（简单左右两列 `pre` 即可）与原因。

## 验收
- 按 F0 通则；截图：站点列表、骑手绑定抽屉、批量奖惩、日标记月历、审计日志展开。
- 走通：新建站点 → 设负责人 → 新建骑手 → 绑定一个启用版本（若 D3 尚无启用版本，先展示空态）→ 批量录入 2 条奖惩 → 审计日志可见。
