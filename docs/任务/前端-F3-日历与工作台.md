## 1. 薪资日历页
- 顶部：SiteSelect → RiderSelect（必选）→ 月份切换（‹ 2026-09 ›，`a-date-picker picker="month"`）；右侧按钮：导出当月明细（跳转/调用对应周期导出）、刷新。
- `SummaryBar`：本月累计单量、应发、奖、惩、代扣、预支抵扣、实发（MoneyText），以及涉及周期 Tag 列表（区间 + 状态颜色：open 蓝/locked 橙/paid 绿/reopened 紫），点击周期 Tag 跳结算周期页。
- `MonthGrid`：**自绘 7 列 CSS Grid，周一起始**，6 行；非本月日期淡显。每个 `DayCell`：左上日期；中部大号「单量」（无数据日显示 `—`）；下部一行科目摘要（净额带符号着色 + 科目名 ≤3 个）；右上状态图标：未导入(灰色虚线边框 + tooltip「未导入」)、无数据(浅灰)、无方案(红色感叹号)、锁账(小锁图标)。
- `PlanBands`：色带层绝对定位在格子顶部区域（每格预留 18px 带区）。算法：把 `plan_bands` 按周行切割；同一行内连续区间渲染为一条横向色带（`grid-column: start / end+1`），左端首格显示短名文字（白字），换周续接时左端显示「↳ 短名」；不同 band 在切换日断开且颜色不同（颜色取 band.color）；无方案区间不画带。hover 显示 tooltip：方案名 V版本号 · 起止。
- 点击日期 → `DayDrawer`（右侧抽屉，宽 720）：`GET /calendar/{rider}/days/{date}`；内容：当日方案与版本、归属周期与状态、日标记 Tag、统计（单量/公式金额/手工奖/手工惩/净额）；Tabs：订单列表（订单号/下单/送达/距离/重量/状态/该单金额，行展开显示命中项 calc_trace 表）、按日项、奖惩明细；底部按钮：「录入奖惩」（跳奖惩页并带 rider/date query）、「查看周期」。
- 无骑手选择时显示空态引导。

## 2. 工作台 `views/dashboard/index.vue`
- 顶部 SiteSelect（全部/单站点）+ 月份。
- `cards`：6 个 `a-statistic` 卡片（在职骑手/本月单量/有效单量/预计应发/待审核预支/待发放预支），点击跳转对应页面。
- `attention`：「待处理事项」区，每一类一个可折叠面板，标题含数量徽标，内容表格 ≤10 行 + 「查看全部」跳 `link`；count=0 的类别**不渲染**。
- `trend`：echarts 折线（近 30 天单量 + 逐单金额双轴）。
- `top_riders`：两列小表（Top10 / 低产 5）。
- 每个模块空数据即隐藏；整页无数据时展示引导「先导入订单明细」。
