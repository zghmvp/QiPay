# 任务 F4 · 前端订单明细、结算周期、预支审核

先读 `docs/任务/前端-F0-通用约定.md`；再读纲要 §1.13–1.17、§4.1–4.3、产品方案第 7 章对应页面与第 8 章文案。后端契约以 `api/v1/{order,period,payroll,advance}.py` 与对应 schema 为准。复用 F1 的组件。

## 你负责
- `api/order.ts`、`api/period.ts`、`api/payroll.ts`、`api/advance.ts` 及 types
- `views/order/index.vue` + `components/{ImportWizard.vue, BatchList.vue, OrderForm.vue}`
- `views/period/index.vue` + `components/{PeriodDetail.vue, PayrollDrawer.vue}`
- `views/advance/index.vue`

## 1. 订单明细
- 筛选：站点/骑手/日期范围/状态/订单号/批次/是否锁账；列表列：订单号/骑手/日期/距离/重量/下单/送达/状态 Tag/来源/锁账图标；行操作：纠错（OrderForm + reason）、删除（reason）。
- 工具栏：「导入」（ImportWizard）、「下载模板」、「补录」（OrderForm）、「导入批次」（BatchList 抽屉：批次列表、状态、成功/失败数、下载错误报告）。
- `ImportWizard`（`a-steps` 三步）：① 选择站点、勾选「跳过错误行」「导入后自动重算」、上传文件（`a-upload-dragger`，xlsx/xls/csv，≤10MB）→ ② 提交并展示结果（成功/失败数、错误表格前 100 行、下载完整错误报告）→ ③ 完成（跳到列表并按批次筛选）。

## 2. 结算周期
- 筛选：站点/骑手（个性化周期）/状态/年月；工具栏：「生成周期」（站点+月份弹窗）。
- 列表：站点/骑手（站点级显示「—」）/周期区间/类型/状态 Tag/骑手数/需重算数(红色)/应发合计/实发合计；行操作按状态显示：算薪（可选骑手，默认全部）、锁账（ReasonModal；后端拒绝时展示 stale 清单）、标记发薪、反冲补发（ReasonModal + 二次确认，说明将生成反冲单）、导出（下载 xlsx）、删除（仅 open 且无结果）。
- `PeriodDetail` 抽屉：周期信息 + payroll 表格（骑手/单据类型 Tag 正常·反冲·补发/状态/单量/应发/代扣/预支抵扣/实发/需重算/计算时间）；点行 → `PayrollDrawer`（二级抽屉或同抽屉 Tabs）：汇总 + 明细按阶段分组表格（行展开 calc_trace）+ 日汇总。
- 页面接受 query `status`、`stale=1`（工作台跳转用）。

## 3. 预支审核
- 筛选：站点/骑手/状态/日期范围；列表：骑手/站点/金额/原因/状态 Tag/申请时间/审核人/发放时间/已抵扣/待抵扣；行操作按状态：通过（备注可选）、驳回（ReasonModal）、标记已发放、取消（ReasonModal）；工具栏「导出预支明细」。
- 详情抽屉：操作时间线（申请→审核→发放→抵扣）。

## 验收
- F0 通则；截图：导入向导结果步、周期列表、PayrollDrawer trace、预支列表。
- 走通：下载模板 → 导入 → 生成周期 → 算薪 → 锁账 → 导出下载成功 → 反冲补发 → 再算薪出现补发单；预支：用 H5 或 curl 创建一笔 pending 后在此页通过 → 标记发放。
