## 3. 公共函数签名与用法

均位于 `backend/plugin/rider_salary/utils/`。

### `deps.py`

```python
async def get_current_rider(request: Request, db: CurrentSession) -> Rider
DependsCurrentRider = Depends(get_current_rider)
async def get_visible_site_ids(request: Request, db: CurrentSession) -> set[int] | None
def assert_site_visible(site_ids: set[int] | None, site_id: int) -> None
```

`Rider` 是 `RiderSalaryRider` 的别名。无骑手或已离职 → 403「当前账号不是有效骑手账号」。超管或角色名「薪资管理员」→ `get_visible_site_ids` 返回 `None`（全部站点）；否则返回 `rs_site_manager` 中该用户的 `site_id` 集合（可为空）。`assert_site_visible` 在集合非空且不含目标站点时抛 403「无权访问该站点数据」。

骑手端：`DependsJwtAuth` + `DependsCurrentRider`，不要挂 `DependsRBAC`。管理端：`DependsJwtAuth` + `RequestPermission('rs:...')` + `DependsRBAC`，并在 Service 里调用 `get_visible_site_ids` / `assert_site_visible`。

### `audit.py`

```python
REASON_REQUIRED_ACTIONS: frozenset[str]
def require_reason(action: str, reason: str | None) -> None
class AuditService:
    async def record(db, request, *, module, action, target_type, target_id, target_label, reason=None, before=None, after=None, description=None) -> None
audit_service = AuditService()
```

写操作调用 `audit_service.record(...)`。`description` 为空时生成「{操作人} 于 {时间} 对 {对象} 执行了 {动作}，原因：{原因}」（无原因则省略后半）。必填原因动作见 `REASON_REQUIRED_ACTIONS`（中文动作名与英文别名均收录）；缺失时抛「请填写操作原因」。

### `lock_check.py`

```python
async def assert_not_locked(db, *, site_id: int, rider_id: int | None, biz_date: date) -> None
```

优先骑手级周期（`rider_id`=该骑手），再站点级（`rider_id=0`）；状态 ∈ `{locked, paid}` → 403「该日期所属结算周期已锁账，禁止修改，请走反冲补发流程」。无周期放行。`rs_settle_period.rider_id` 为 **NOT NULL DEFAULT 0**，0 表示站点级；唯一约束 `(site_id, rider_id, start_date, deleted)`。

### `recalc.py`

```python
async def mark_stale(db, *, rider_ids: Iterable[int], date_from: date, date_to: date) -> int
```

将日期范围与 `open`/`reopened` 周期相交、且状态为 `draft` 的 `rs_payroll.stale` 置 `True`，返回影响行数。周期范围只含这些骑手的骑手级周期及 `rider_id=0` 的站点级周期。不 `commit`。

### `periods.py` / `money.py`

```python
def compute_period_range(cycle_type, cycle_config: dict | None, any_date: date) -> tuple[date, date]
def q2(value) -> Decimal  # ROUND_HALF_UP 到 2 位
```

自定义 `{"anchor_day": N}`：N=1 等价月结；N 大于当月天数时起点钳为当月最后一天（如 2 月 anchor=31 → 2/28 或 2/29 起，至 3/30）。

## 9. D6 对外签名与 /me 返回结构

**签名**  
`calendar_service.build_month(db, rider_id, month, *, request=None, for_rider=False) -> GetCalendarMonth`  
`calendar_service.build_day(db, rider_id, biz_date, *, request=None, for_rider=False) -> GetCalendarDayDetail`  
`advance_service.transition(advance, target, operator, reason)`；非法 → 400「预支单当前状态为 X，不允许执行 Y」。另：`get/get_list/approve/reject/mark_paid/cancel/export/submit_for_rider/cancel_for_rider`。

**`/me/*`（JwtAuth + CurrentRider，无 RBAC）**  
`profile`：工号/姓名/站点/用工/入职/`current_plan{version_id,plan_name,short_name,version_no,mode_tag,start_date,end_date}`/`advance_limit`/`has_in_flight_advance`  
`calendar`：同管理端月历；`days/{date}`：plan/period/orders+科目金额（无表达式）/daily_items/adjustments/totals  
`payroll-estimate`：`{period_range,period_status,order_count,gross,deduction_total,advance_deduction_estimate,net_estimate,is_estimate,updated_at}`  
`adjustments`：科目/方向/金额/日期/备注；`plan`：当前+未来绑定（项名+科目）；`notices`：已发布公告  
`advance-limit`：`{limit,used_pending_amount,available}`；`advances` GET/POST `{amount,reason}`；`POST .../cancel`。
